## 核心设计：五道筛子（AI 适配度评估标准）

每项工作任务逐项过筛，全过的就是高适配场景：
1. **高频**——天天/每周做，不是一年一次
2. **重复**——步骤稳定可复制，不靠临场发挥
3. **规则明确**——判断标准说得出口、写得出
4. **结构化**——输入输出有固定格式（表格/模板/固定话术）
5. **容错**——出错有人工复核兜底，不致命

再加一条隐性前提写在引擎里：**素材在公司内拿得到**（涉密数据出不去的场景，
优先考虑本地化/信创方案，这正是你课程强调过的合规点）。

## 两段式工作流

勘探（interview）→ 锁定 TOP1 场景 → 开采（prd）→ 入场景库（archive）

勘探阶段不许写 PRD：场景没盘清就写需求，是甲方 AI 项目失败的第一大原因。

## 面向甲方的使用建议

- 员工个人版：一人盘点自己的活，产出个人级 PRD
- 部门工作坊版（适配你的课）：20 个学员现场盘点，产出部门级场景地图，
  五道筛子打分环节天然形成小组讨论
