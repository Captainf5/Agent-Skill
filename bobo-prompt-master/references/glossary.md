# 术语速查

这十来个词，是看完全稿最容易卡住的地方。每个一句话说清，不用记，用到回来查。

| 词 | 一句话解释 |
|---|---|
| 大模型 | AI 的「大脑」。不同公司训练出来的版本，能力、价格、擅长的事都不一样。换模型，换的就是这个大脑 |
| Token | AI 的计费单位，约等于「字数」。你给它的资料、它写出的回答都按这个算钱，读得越多花得越多 |
| 提示词（Prompt） | 你交代给 AI 的那段话。同一件事，说得清不清楚，结果能差一个档次——这就是 P |
| 上下文（Context） | AI 这一次能看到的全部材料：你贴的文件、它查到的资料、前面聊过的内容。看不到的等于不存在——这就是 C |
| 权限（Permission） | AI 被允许动哪些文件、连哪些系统、能不能自己跑。给多了危险，给少了它干不了活——这就是 R |
| Agent（智能体） | 不只是陪你聊天、还能自己动手干活的 AI：能读文件、能调工具、能按流程跑完一件事 |
| MCP | 给 AI 用的「通用接口」，让它能接上你已有的系统。有了它，AI 才不用你每次手工搬数据 |
| 技能（Skill） | 把一套跑通的流程打包存下来，下次一句话就能再调出来。本框架的「合」最适合做成技能 |
| 知识库 | 存起来、随时能被 AI 翻查的资料库——附件是这一次用，知识库是以后都能用 |
| 幻觉 | AI 一本正经地编造不存在的事实。防它只有一个办法：限定「必须来自我给你的材料」 |

只记三个词也够：提示词是「怎么说」，上下文是「给它看什么」，权限是「让它动什么」。其余概念基本都能挂在这三条底下。
