# 案例怎么写给我（模板）

不用整理格式，照着填或者直接贴都行。**只填第 3 行也能开始。**

---

**1. 客户是谁**
什么行业、体量大概什么级别、你卖的是什么。
> 例：汽车零部件厂，年采购额几千万，我们供微电机。

**2. 现在到哪一步**
线索 / 已拜访几次 / 报过价 / 在等招标 / 卡在合同。一句话就够。
> 例：报价发过去两周了，微信不回。

**3. 原始材料（最重要，直接贴，不要改写）**
客户原话、邮件原文、会议纪要、招标文件片段、微信群聊截图转文字。
**别帮我总结，也别替客户润色。** 客户的原话里有情绪和回避，那些才是判断依据。

**4. 你已经做过什么**
已经给过什么方案、降过几次价、找过谁、对方怎么回应。

**5. 你最想解决哪一点**
只写一个。比如"想知道这单还值不值得跟"或"下次见面怎么开口"。

---

## 几个提醒

- **敏感信息可以脱敏**：客户名、金额、人名去掉，不影响判断。
- **一次可以发多个案例**，我逐条给，不用等。
- **不知道怎么写就只贴聊天记录**，我从里面找线索。
- 如果材料里有你不确定真假的内容，标一下"这个我不确定"，我不会当成事实用。
